# PersonaOS 0.12.0 portability addendum

本补充版本把 `persona-export-v1` 从“可校验导出”推进为真实的迁移/恢复闭环：

- `POST /api/v1/personas/import` 校验 manifest、schema、完整来源图谱与每份原始资料
  的 SHA-256；
- 保留稳定 Persona UUID，并把数据归属映射到已认证的目标本地账户；
- 原始 Blob 使用目标环境密钥重新 AES-256-GCM 加密，不迁移旧密钥或内部 object key；
- 恢复人物、资料、chunk、记忆、不可变版本、证据、关系、对话、引用和审计历史；
- 不导出向量数组，恢复后用目标环境的本地 embedding space 重建确认记忆索引；
- 外部模型边界始终重置为仅 `local`，避免备份隐式携带数据出境授权；
- Web 空工作区新增 JSON 恢复入口；相同 UUID 冲突会明确拒绝，不静默覆盖；
- 新增跨 SQLite 数据库、不同 Blob 密钥、应用重建、问答回忆、人物隔离与篡改拒绝
  的端到端测试。
