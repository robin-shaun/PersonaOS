# ADR 0001：记忆隐私生命周期采用追加版本、边界硬过滤与两阶段来源删除

- 状态：Accepted
- 日期：2026-07-25
- 决策版本：PersonaOS 0.9.0

## 背景

人物资料包含可识别、敏感且可能属于第三方的内容。M3 必须同时支持确认后修正、
模型调用、关系、导出和删除，并满足三条不可互相替代的要求：

1. 修正不能静默篡改历史；
2. 不允许发送给某个模型的数据不能先进入该模型再靠 prompt 约束；
3. 删除不能只隐藏顶层记录，而留下向量、引用、回答正文或孤立 Blob。

数据库事务无法与文件系统 Blob 删除形成真正的分布式原子提交，因此需要明确
失败状态和重试语义。

## 决策

### 1. 确认后编辑只追加版本

调用者提交当前 `expected_version`。事务锁定 Memory 后创建不可变的新版本，再
切换 `current_version_id`。正文发生用户改写时，新的 epistemic status 变为
`user_asserted`，`source_bound=false`，证据关系变为 `derived_from`。旧版本
保留，但检索只接受当前版本。

### 2. 模型数据边界是查询条件

Persona 保存允许的 `local`、`private_network`、`external` 边界，默认只有
`local`。生成器和 embedding provider 必须先声明边界。边界映射到允许的敏感
等级，并同时加入词法、向量、证据查询和向量化候选查询。启用 `external` 需要
显式确认，且它只能接收 `public` 记忆。非本地生成器只接收允许的 Memory 摘要
和 citation ID，不接收原始 evidence excerpt、文件元数据或 locator；完整证据
只在本地用于生成后 citation 校验与落库。

### 3. 来源删除使用可重试的两阶段流程

第一阶段把资料锁定并改为 `deleting`；若导入任务仍在排队则先取消。随后按全局
`object_key` 引用计数决定是否删除 Blob。第二阶段在单个数据库事务中：

- 擦除曾使用目标记忆的回答正文、claims 和全部 citations；
- 使 RetrievalRun 和 ModelCall 失效；
- 删除关系、所有 embedding 空间的向量、证据、版本、记忆、chunk 和资料；
- 写入不含正文的审计墓碑，作为幂等重试回执。

Blob 删除失败时不执行第二阶段，资料保持 `deleting`。相同 Blob 有其他资料引用
时不删除物理对象。当前单 API 进程使用进程锁协调上传和删除。

### 4. 导出不包含向量数组

导出是带 schema version 和 SHA-256 manifest 的 JSON 快照。可选包含解密原文，
但只输出 embedding 空间和内容哈希元数据，不输出向量数组。当前整体缓冲并受
`PERSONA_MAX_EXPORT_BYTES` 限制。

## 未选择的方案

- 原地覆盖 Memory 正文：无法可靠还原人物在某一时点的证据状态。
- 只在 prompt 中写“不要使用敏感记忆”：数据已经越过供应商边界，约束太晚。
- 只做软删除：向量、引用和派生回答仍可能返回已经请求删除的内容。
- 删除审计事件：会失去谁在何时删除何种资源的责任链；改为仅保留 ID、哈希和
  计数的墓碑。
- 在一个数据库事务内假装 Blob 与 SQL 原子提交：文件系统操作无法随 SQL 回滚，
  会产生不可恢复的假一致性。

## 后果与限制

- 版本化编辑会保留旧版本及旧向量，占用额外存储；当前版本过滤保证它们不召回。
- 硬删除会有意破坏历史回答的原正文可读性，以删除权优先于回答复现。
- 应用回执证明当前数据库和 BlobStore 不再返回目标，不是物理介质净化证明。
  NIST SP 800-88 Rev. 2 所讨论的介质净化需要结合存储介质、备份和密钥生命周期
  单独实施：[NIST SP 800-88 Rev. 2](https://csrc.nist.gov/pubs/sp/800/88/r2/final)。
- 多 API 副本尚无跨进程 Blob 引用租约；扩容前必须增加数据库 advisory lock、
  专用对象目录表或对象存储生命周期协调器。
- 大导出仍需后续改为流式归档和单独下载授权。

## 验证

端到端测试必须覆盖：

- 乐观锁冲突和三代不可变版本；
- 外部生成器及外部 embedding 只收到 `public` 记忆；
- 关系两端与证据版本归属校验；
- 导出含原始资料但不含向量和内部 object key；
- 来源删除后 Blob、chunk、memory、version、evidence、embedding、citation、
  词法结果和向量结果均为空；
- 依赖回答被擦除，重复删除返回同一审计回执，审计 JSON 不含原正文；
- 共享 Blob 只在最后一个资料引用删除后移除。
