# Repository Instructions

## Delivery

- For every repository update, create a Git commit containing the files changed for the current task before finishing.
- Push every new commit to `https://github.com/robin-shaun/PersonaOS.git` on the current branch.
- Stage only task-related files; do not include unrelated pre-existing worktree changes.
- Run relevant checks before committing and report both the commit ID and push result.
- If committing or pushing fails, report the failure instead of claiming completion.
